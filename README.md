# Isometrica

Routine isometrica mattutina in tre giorni: figure animate di ogni esercizio con i muscoli coinvolti, le spinte da fare una alla volta e una sessione guidata con timer, beep e voce.

Funziona offline e si installa sul telefono come app: aprila in Chrome su Android e scegli **Installa app** dal menu.

I tempi impostati restano salvati sul dispositivo.
